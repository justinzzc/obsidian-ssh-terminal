# 运行期终端实例与独立终端视图设计

## 目标

为 Obsidian SSH Terminal 增加左侧 Ribbon 入口和运行期终端实例管理能力。用户从 Markdown 中启动 SSH 后，即使切换到其他文档，真实 SSH 会话和终端状态仍继续运行；用户可以从左侧实例列表打开唯一的独立 Terminal 标签页，也可以回到初始来源文档，将活动终端重新激活到原 `ssh` block 中。

本版本只保证单次 Obsidian 运行期间保活。关闭或重启 Obsidian 后，不恢复 SSH 会话或实例列表。

## 核心原则

- 一个运行时实例同一时间最多拥有一个 SSH 会话，并始终拥有一个 xterm 实例。
- 同一终端界面同一时间只挂载在一个位置，避免多个界面争用输入和输出。
- 终端可在来源文档、独立 Terminal 标签页和后台三种位置之间迁移。
- 初始来源只在首次从 Markdown 启动时记录，之后不会因界面迁移而改变。
- 不持久化密码、命令输入、终端输出或活动会话元数据。
- 插件卸载或 Obsidian 退出时关闭所有 SSH 会话。

## 用户体验

### 左侧入口与实例列表

插件通过 Ribbon 注册终端图标。点击图标打开左侧 `SSH Sessions` 侧边栏。

实例只在用户从 `ssh` block 点击 `Connect`、实际创建 SSH 会话后加入列表。仅渲染但从未连接的 block 不产生实例。

列表按最近活动时间排列，每项显示：

- profile 名称；inline 模式显示 `username@host:port`。
- 会话状态：Connecting、Connected、Disconnected 或 Failed。
- 初始来源文档路径。
- 当前界面位置：Document、Terminal tab 或 Background。
- 打开终端、打开来源、断开连接和移除记录操作。

来源文档路径可点击并打开对应文档。来源文档不可用时显示明确状态，不隐藏或终止实例。

### 独立 Terminal 标签页

点击列表中的实例会创建或聚焦该实例唯一的独立 Terminal 标签页，不重复创建标签页。

标签页显示：

- 实例名称和会话状态。
- 初始来源文档路径及“打开来源文档”操作。
- 完整终端界面，以及 Clear 和 Disconnect 操作。
- 当终端当前挂载在来源文档时，显示“当前已激活到来源文档”和“在此激活”按钮。

关闭独立标签页只会关闭界面 Host。活动实例转入后台，SSH 会话继续运行。

### 来源文档中的激活行为

实例首次连接时，完整终端显示在来源 `ssh` block 中。

切换文档导致来源 block 卸载时，终端从 DOM 安全脱离并转入后台，但 SSH 会话和 xterm 状态继续存在。用户从左侧列表打开实例时，终端迁入独立标签页。

再次打开来源文档后：

- 如果来源 block 能与活动实例匹配，block 显示实例状态、当前位置和“激活”按钮。
- 点击“激活”后，同一个终端 DOM 和 xterm 实例迁回文档。
- 独立标签页继续存在，但显示终端当前位于来源文档，并提供“在此激活”按钮。
- 如果终端已经在来源文档中，重复操作只聚焦现有界面，不创建新实例。

## 运行时数据模型

### TerminalInstanceRegistry

`TerminalInstanceRegistry` 是所有活动与历史实例的运行时唯一事实源，负责：

- 创建和去重实例。
- 查询实例和发布列表变化。
- 记录初始来源元数据。
- 在 Host 之间迁移唯一终端界面。
- 将没有可用 Host 的实例置于后台。
- 断开 SSH 会话。
- 在实例已断开后移除记录。
- 插件卸载时关闭并释放全部实例。

### TerminalInstance

每个 `TerminalInstance` 持有：

- 稳定的运行时 `instanceId`。
- 当前 `SshSession`；断开后重新连接时创建替代会话，不并存多个会话。
- 唯一 xterm/终端界面对象。
- 运行时连接目标解析器，用于显式重新连接。
- 初始来源文档路径。
- 来源 block 指纹。
- 不含密码的连接展示信息。
- 当前会话状态。
- 当前 Host 类型和标识。
- 独立 Terminal View 的 leaf/view 关联。
- 最近活动时间。

### 来源 block 身份

来源 block 身份由以下信息组合：

- 初始来源文档路径。
- 规范化后的 `ssh` block 内容指纹。
- 同一文档内内容相同的 `ssh` block 序号。

该身份不依赖绝对行号，因此在文档其他位置插入或删除普通文本时仍能匹配。用户修改原 `ssh` block 的连接配置后，指纹改变，系统不得把活动会话附加到新配置；实例继续在列表、独立标签页或后台运行，但不再提供激活到该 block 的能力。

来源元数据不得包含密码。profile 模式只记录 profile ID/展示名；inline 模式只记录 host、port、username、展示名和安全的运行时连接签名。实例可以在内存中保留现有连接目标解析器，以支持运行期显式重新连接；解析器中的凭据能力不得出现在注册表快照、View state、日志或持久化数据中，并在实例移除或插件卸载时释放。

## 组件边界

### TerminalInstanceRegistry

只负责实例生命周期与状态，不创建 Obsidian DOM 布局。界面通过订阅获取不可变快照。

### TerminalHost

统一表示可承载终端的目标位置：

- Markdown block Host。
- 独立 Terminal ItemView Host。
- Background，无 DOM 容器。

Host 提供稳定标识、容器可用状态和销毁通知。注册表负责原子迁移：目标有效时才从当前 Host 脱离；目标在迁移过程中销毁时，保留原 Host，原 Host 也不可用时转入后台。

### SshSessionsView

Obsidian 左侧 ItemView，只订阅注册表快照并发送用户意图：打开实例、打开来源、断开或移除。它不直接持有 SSH 会话。

### PersistentTerminalView

Obsidian 主工作区 ItemView。每个实例使用稳定 view state 识别。重复打开同一实例时聚焦已有 leaf；view 关闭时注销 Host，但不关闭会话。

### Markdown 渲染器

阅读视图和实时预览共享来源身份生成与实例查找规则。渲染器负责：

- 未存在实例时显示普通 Connect 入口。
- 首次连接时向注册表创建实例并记录来源。
- 来源实例位于其他 Host 或后台时显示激活占位界面。
- 用户点击激活时注册当前 block Host 并请求迁移。
- block 卸载时仅注销 Host，不再直接关闭注册表拥有的会话。

## 生命周期与数据流

### 首次连接

1. Markdown 渲染器解析 block 并生成来源身份。
2. 用户点击 Connect。
3. 注册表检查该来源是否已有实例。
4. 不存在时创建 `TerminalInstance`、SSH 会话和唯一终端界面。
5. 实例加入左侧列表，终端挂载到当前 block Host。
6. 已存在时聚焦或激活现有实例，不创建第二个会话。

### 打开独立终端

1. 用户点击左侧列表项。
2. 插件查找该实例已有的 Terminal leaf。
3. 已存在则聚焦；不存在则创建带实例 ID 的 ItemView。
4. ItemView 注册 Host，注册表把唯一终端迁入该 Host。

### 激活到来源文档

1. 来源文档重新渲染 `ssh` block。
2. 渲染器用来源身份查找活动实例。
3. 匹配时显示激活占位界面。
4. 用户点击激活，注册表把终端从标签页或后台迁入 block Host。
5. 原独立标签页显示当前位置提示，不销毁实例。

### 断开与移除

- Disconnect 显式关闭 SSH，会话状态变为 Disconnected，实例记录继续存在。
- 已断开的实例可从列表或对应界面重新连接；重新连接创建新的 `SshSession`，继续使用原 xterm 界面。
- Remove 只对已断开的实例开放，并释放终端对象、Host 关联和运行时元数据。
- 活动实例必须先断开，不能通过 Remove 隐式终止 SSH。

## 文档变化处理

- 文档重命名：监听 vault rename，更新实例的来源路径和来源身份索引。
- 文档删除：保留实例并标记来源不可用；关闭“打开来源”和“激活到文档”操作。
- 来源 block 删除：实例继续运行；文档渲染结束后没有匹配 Host，实例维持标签页或后台状态。
- 来源 block 修改：新指纹不匹配旧实例，不允许错误激活。
- 多窗格打开同一文档：同一来源身份仍对应同一实例；激活到某个 block Host 后，其他 block Host 显示当前位置提示。

## 异常处理

- Terminal View 创建失败：实例保持原 Host；没有原 Host时转入后台，并在列表显示错误。
- Host 在迁移过程中销毁：迁移回滚到原 Host；无法回滚时转入后台。
- SSH 连接失败：实例状态变为 Failed，保留来源信息和重连入口。
- 来源文档无法打开：显示 Notice 和不可用状态，不影响会话。
- 插件卸载：停止 UI 订阅，关闭全部 SSH 会话，释放 xterm 和 Obsidian View。
- 同一来源重复 Connect：返回已有实例并激活，避免并发创建。

## 安全与隐私

- 注册表只存在于内存，不写入 `data.json`。
- 不保存终端输出、命令输入或滚动历史的副本；滚动历史仅存在于 xterm 内存中。
- 不在实例元数据、View state、日志或 Notice 中保存 password。
- profile 密码继续由现有 `safeStorage` 流程读取。
- inline 密码仍只来自原 Markdown block；来源元数据不复制该字段。

## 测试策略

### 单元测试

- 注册表创建实例、按来源去重和发布状态快照。
- 文档、标签页和后台 Host 之间迁移时保持同一终端对象与同一 SSH 会话。
- Host 销毁、迁移失败和后台回退。
- Disconnect 保留记录，Remove 拒绝活动实例并允许移除已断开实例。
- 来源指纹在普通文本移动后仍匹配，block 配置变化后拒绝匹配。
- 文档重命名更新来源路径，文档删除标记来源不可用。
- 密码、输入和输出不会进入注册表快照或持久化数据。

### Obsidian 集成边界测试

- Ribbon 注册并打开唯一 `SSH Sessions` 侧边栏。
- 左侧列表创建、更新、排序及操作回调。
- 独立 Terminal ItemView 按实例 ID 创建、复用和聚焦。
- 关闭独立标签页只注销 Host，不关闭会话。
- 阅读视图和实时预览生成一致的来源身份并显示正确的激活占位状态。
- 插件卸载关闭全部会话并释放视图资源。

### 回归验证

- 原有 inline 和 profile 连接方式继续工作。
- 主机指纹确认、凭据安全存储和错误映射行为不改变。
- 现有 Reading View、Live Preview、TerminalView 和 SessionManager 测试继续通过。

## 非目标

- 跨 Obsidian 重启恢复会话或实例列表。
- 同一实例同时显示在多个可交互终端界面。
- 保存或回放终端输出。
- 实例搜索、分组、手动排序或重命名。
- SFTP、端口转发、跳板机、私钥、SSH Agent 或移动端支持。
